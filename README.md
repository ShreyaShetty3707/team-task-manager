# TeamTask - Collaborative Team Task Manager

TeamTask is a small full-stack collaborative task management application.

## Features

- Add new tasks
- Edit tasks
- Delete tasks
- Change task status
- Search tasks
- Dashboard task statistics
- Team member section
- Responsive design
- SQLite database
- Flask backend
- HTML, CSS and JavaScript frontend

## Technologies

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Git
- GitHub
